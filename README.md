# رزم‌نامه: نبرد افسانه‌ای شاهنامه | Razmnameh: Legends of Shahnameh

یک بازی اکشن پلتفرمر ۲بعدی و فایتینگ تن‌به‌تن حماسی (1v1 Duel Arena) با الهام از شاهنامه جاودان حکیم ابوالقاسم فردوسی، با طراحی حرفه‌ای، پایداری بدون ارور، سیستم روایت صوتی نقالی و سازگاری کامل با تمامی دستگاه‌ها (رایانه، تبلت و گوشی‌های هوشمند).

---

## 🌟 ویژگی‌های کلیدی بازی (Key Features)

1. **کمپین داستانی هفت‌خان و فصول حماسی شاهنامه:**
   - هفت فصل بزرگ شامل خان اول (بیشه شیر ژیان)، خان پنجم (اولاد دیو)، خان هفتم (غار دیو سپید)، نبرد تراژیک رستم و سهراب، گذر سیاوش از آتش، نبرد هفت لشکر، و رزم با اسفندیار رویین‌تن.
   - روایت مصور پرده‌خوانی و نقالی سنتی قبل از هر نبرد همراه با شاه‌بیت‌های اصیل فردوسی و نوای ضرب و زنگ باستانی زورخانه.

2. **سیستم مبارزه تن‌به‌تن سینمایی (1v1 Duel Arena):**
   - مبارزه رو در رو با قهرمانان و هماوردان (سهراب یل، دیو سپید، اسفندیار رویین‌تن، گردآفرید).
   - **مکانیک قفل تیغه‌ها (Blade Clash QTE):** هنگام برخورد همزمان ضربات، تیغه‌ها قفل شده و بازیکن با تپ سریع حریف را به عقب رانده و گارد او را می‌شکند.

3. **قهرمانان قابل بازی با جزییات بالا:**
   - **رستم دستان (تَهمتَن):** گرز سام، کلاه‌خود سیمین، ببر بیان با خطوط ببری و ریش و سبیل حماسی.
   - **سهراب یل:** شمشیر دودَم کیانی، فک تراشیده و چابکی بی‌همتا.
   - **گردآفرید شیرزن:** تیرانداز چیره‌دست با کمان آرش و خنجر مرصع.

4. **سیستم صوتی و نقالی تعاملی:**
   - صدای زنگ مرشد و ضرب زورخانه ساخته‌شده با Web Audio API بدون نیاز به فایل‌های حجیم خارجی.
   - سیستم بازخوانی صوتی ابیات و نثر کهن شاهنامه با قابلیت فعال/غیرفعال‌سازی.

5. **طراحی واکنش‌گرا و کنترل لمسی حرفه‌ای:**
   - کلیدهای کنترلی مجازی ارگونومیک برای صفحات لمسی موبایل با افکت شیشه‌ای (Frosted Glass).
   - پشتیبانی کامل از کیبورد در دسکتاپ (A/D حرکت، Space پرش، J ضربه سبک، K ضربه سنگین/تیر، L دفاع/دفع، U مهارت فرّه ایزدی).

6. **تنظیم کیفیت گرافیکی پویا (Graphics Tier System):**
   - چهار سطح کیفیت (کم، متوسط، بالا، اولترا) با سیستم بهینه‌سازی سایه‌ها، ذرات خون و جرقه‌ها، و نورپردازی فرّه.

## 🕹️ راهنمای کلیدهای بازی (Controls)

| عملکرد | کلید کیبورد | کنترل لمسی موبایل |
| :--- | :--- | :--- |
| **حرکت به چپ و راست** | کلیدهای `A` و `D` یا `←` و `→` | دکمه‌های جهت‌نمای چپ/راست |
| **پرش** | `Space` یا `W` یا `↑` | دکمه پرش (▲) |
| **ضربه رزمی سبک / کامبو** | کلید `J` | دکمه حمله (⚔️) |
| **ضربه سنگین / تیراندازی / دش** | کلید `K` | دکمه دش / تیر (⚡ / 🏹) |
| **دفاع و دفع ضربه (Parry)** | کلید `L` | دکمه سپر (🛡️) |
| **فرّه ایزدی / خشم پهلوانی** | کلید `U` | دکمه فرّه (⚡) |
| **تپ سریع در قفل تیغه‌ها** | کلید `Space` یا `J` | کلید بزرگ تپ فشاری |

## 🛠️ نصب و راه‌اندازی محلی (Development & Build)

برای اجرای پروژه روی سیستم شخصی خود:

```bash
# کلون کردن مخزن
git clone <repository-url>
cd razmnameh

# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه محلی
npm run dev

# بررسی عدم وجود خطای تایپ‌اسکریپت
npm run lint

# ساخت نسخه پروداکشن برای پابلیش
npm run build
```
